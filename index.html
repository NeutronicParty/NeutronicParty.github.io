NEngine

One script. Every page.

NEngine is a Tampermonkey userscript that loads the Neutronic Engine into any page you visit. Install it once — the loader pulls the latest engine straight from source, so it stays current on its own.

  • ✓v1.04 — self-updating loader
  • ✓Works with Tampermonkey or Violentmonkey
  • ✓Runs at document-start and injects into page context
