01 What you're actually installing

Three separate pieces fit together. Understanding them makes every error message make sense.

  • Tampermonkey — a browser extension that can run small pieces of code ("userscripts") on the pages you visit. It's the engine that lets any of this work.
  • The Neutronic Loader — the userscript itself (nengine.user.js). It's tiny: it fetches the real engine and injects it into the page.
  • Neutronic Engine — the actual code the loader downloads from GitHub every time a page loads. You never install this part manually; the loader keeps it current for you.

So the install is really: get Tampermonkey → let it run userscripts → install the loader. The loader handles the rest forever.

02 What you need first

  • A desktop browser — Chrome, Edge, Brave, Opera, Firefox, or Safari. Mobile browsers generally can't install extensions, so this is a desktop job.
  • Permission to install extensions (a personal computer, not a locked-down school or work machine).
  • About two minutes.

One thing to know up front: Chrome and other Chromium browsers (Edge, Brave, Opera) now require you to switch on an extra setting called Allow User Scripts before Tampermonkey is allowed to run anything. Firefox does not. Step 2 covers it.

03 Step 1 — Install Tampermonkey

Go to tampermonkey.net and click the download button for your browser. Or install it straight from your browser's own store:

Chrome

Open the Chrome Web Store, search Tampermonkey, and click Add to Chrome → Add extension.

Or use the official link on tampermonkey.net, which points at the same listing.

Edge

Open the Microsoft Edge Add-ons store, search Tampermonkey, click Get → Add extension.

Brave

Brave uses the Chrome Web Store. Open it, search Tampermonkey, click Add to Chrome → Add extension.

Opera

Opera uses the Chrome Web Store too (Opera add-ons also lists it). Install from either, confirm Add extension.

Firefox

Open Firefox Add-ons (addons.mozilla.org), search Tampermonkey, click Add to Firefox → Add.

Firefox will ask what permissions to grant — allow them so userscripts can run.

Safari (macOS)

Safari support depends on your macOS version and requires enabling extensions in Safari → Settings → Extensions. If Tampermonkey isn't available for your version, use Chrome or Firefox instead — they're the most reliable for this.

After it installs, Tampermonkey usually opens a welcome tab. You'll also see its icon (a small black-and-white square) in your toolbar. If you don't see the icon, click the puzzle-piece / extensions button in the top-right of the toolbar and pin Tampermonkey so it's always visible.

04 Step 2 — Allow user scripts

This is the step almost everyone misses, and it's the reason a script can appear "installed" but do nothing.

On Chrome, Edge, Brave, and Opera

  1. Click the puzzle-piece / extensions icon in the top-right of the browser toolbar. (If you don't see it, open the browser menu → Extensions → Manage extensions.)
  2. Find Tampermonkey in the list and click Details.
  3. Scroll down to the Allow User Scripts toggle and switch it ON.

That toggle is required. Without it, the browser blocks Tampermonkey from running any userscript, and NEngine will silently do nothing.

On Firefox

There's no separate toggle — once Tampermonkey is installed and permitted, it can run userscripts. Skip to Step 3.

Why this exists: Chromium browsers added the toggle as a security measure so extensions can't run arbitrary code without you explicitly saying yes. Flipping it on is expected and safe — it only affects Tampermonkey, not every site.

05 Step 3 — Install NEngine

  1. Click the Install NEngine button below (or on the Help page). It opens nengine.user.js.
  2. Tampermonkey intercepts the file and shows its own installation screen with the script name Neutronic Loader and a version number.
  3. Click Install (sometimes labelled Reinstall or Update if you've had it before).
  4. That's it. There's no separate download, no folder, no setup. The loader is now active on every page.

If clicking the button shows raw code instead of Tampermonkey's install screen, Tampermonkey isn't installed or isn't enabled — go back to Step 1.

06 Step 4 — Confirm it's running

The loader logs what it does, so you can check it in seconds.

  1. Open any website.
  2. Press F12 (or right-click → Inspect) to open developer tools, then click the Console tab.
  3. Look for a blue line beginning with [Neutronic Loader]. A message like script executed in page context (… bytes) means it's working.

You can also click the Tampermonkey icon → Dashboard, and confirm Neutronic Loader is listed and enabled (the toggle beside it is on).

Don't panic if the console looks empty. Some sites clear the console or block scripts. Try a plain site first, and check the Tampermonkey Dashboard instead — if the script is listed and enabled, it's installed correctly.

07 Troubleshooting

Match the symptom, apply the fix.

SymptomCause & fix
Clicking Install shows raw codeTampermonkey isn't installed or is disabled. Reinstall it (Step 1) and make sure the extension is switched on.
Script installs but nothing happensThe Allow User Scripts toggle is off. Chrome/Edge/Brave/Opera: extension Details → toggle ON (Step 2).
Console shows HTTP 404The loader couldn't reach the engine file on GitHub. Usually temporary, or the source moved — check the Discord if it persists.
Console shows content-type warningThe server returned an error page instead of the script. Reload the page; if it continues, report it in Discord.
page eval failed / CSP warningThe site's Content-Security-Policy blocks injection. The loader tries three fallbacks automatically; on a few strict sites it still can't run. That's the site, not your install.
Works on some sites, not othersNormal. Sites with strict CSP or sandboxing can block userscripts. The install is fine.
Tampermonkey icon missingIt's unpinned. Click the puzzle-piece icon and pin it, or open the browser's extensions menu.
Nothing at all, no icon, no promptExtension didn't install (blocked by policy?). On a managed/school device extensions may be disabled entirely — use a personal machine.

08 Updating & removing

Updating

You don't need to do anything. The loader always fetches the newest engine from source with a cache-buster, so every page load runs the current version. When the loader itself changes version, re-run the install from Step 3 and Tampermonkey will offer Update.

Removing NEngine

  1. Click the Tampermonkey icon → Dashboard.
  2. Find Neutronic Loader in the list.
  3. Click the trash-can icon beside it (or open it and choose Delete).

To remove Tampermonkey itself, go to your browser's Manage extensions, find Tampermonkey, and choose Remove.

Privacy: what NEngine logs, what it doesn't, and how to opt out are all spelled out on the Info page.
