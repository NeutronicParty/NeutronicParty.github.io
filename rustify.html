Rustify

A native YouTube Music client written in Rust. No browser, no Electron, no Spotify client — just GTK, yt-dlp, and one small binary.

Install What it does

Linux · GTK3 · yt-dlp · open source

What it is

Music, without the browser.

Rustify is a native desktop client for YouTube Music. Search and stream resolution go through yt-dlp; audio is decoded and played by rodio over cpal. Art comes straight from YouTube's CDN. The UI is GTK3, with WebKitGTK used only for the YouTube Music login cookie — the app itself is not a web wrapper.

Native GTK3A real desktop window, real menus, real keyboard focus. No Chromium under the hood.
yt-dlp streamingSearch, resolve, and stream tracks with the same extractor the rest of the world uses.
Downloads & importsSave the current track to an imports folder and play local files alongside streams.
LyricsSynced lyrics from lrclib.net with a Genius fallback, right in the player and mini player.
ThemesPurple Rustify is the default; other palettes swap the whole sheet without moving the layout.
Small and fastOne stripped Rust binary, no Electron, no bundled browser, low memory at idle.

Install

One command. Nothing else needed.

Run this in a terminal on a Linux desktop. It sets up everything from scratch — system packages, Rust if it is missing, yt-dlp, the app, a launcher, and the imports folder. You do not need an installer, an app image, a source folder, or any files before you run it.

curl -fsSL https://strangergithun.github.io/install-rustify.sh | bash

Paste it into a terminal and press Enter. It will ask for your sudo password for the system packages.

  1. Open a terminal on your Linux desktop.
  2. Paste the command above and press Enter.
  3. Enter your sudo password when it asks — that is for GTK, WebKitGTK, ffmpeg, and the other system pieces.
  4. Wait. The script downloads the source, installs dependencies, installs Rust 1.80+ via rustup if needed, builds Rustify when the prebuilt binary cannot run, and unpacks yt-dlp for fast startup.
  5. Rustify launches when it is done. After that, run rustify or open it from the app menu.

What the command sets up

From empty machine to working app.

The script is not a wrapper around an existing install — it is the install. It detects apt, dnf, pacman, zypper, or apk and installs the runtime and build packages it needs. Then it puts everything in the right place under your home directory.

System runtimeGTK3, WebKitGTK 4.1, libsoup3, OpenSSL, ALSA, ffmpeg, Python 3, curl, librsvg, and the Inter font.
Rust toolchainIf rustc/cargo are missing or older than 1.80, rustup installs a stable toolchain.
yt-dlpThe latest yt-dlp zipapp, unpacked and precompiled under ~/.local/share/rustify for fast calls.
The app~/.local/bin/rustify — a single native binary you can launch from anywhere.
Launcher + iconA desktop entry in ~/.local/share/applications and the icon in your hicolor theme.
Imports folder~/.local/share/rustify/imports for downloaded tracks and local files.

Requirements

What you need first.

A Linux desktop with X11 or Wayland — Debian/Ubuntu/Mint, Fedora, Arch, openSUSE, and Alpine are detected automatically. An internet connection for the download, packages, and yt-dlp. sudo access for system packages. About 2 GB free disk if the machine has to build from source; much less when the prebuilt binary runs.

Troubleshooting

If something sticks.

rustify: command not found — ~/.local/bin is probably not on your PATH. Run ~/.local/bin/rustify directly, or add export PATH="$HOME/.local/bin:$PATH" to your shell profile.

The prebuilt binary will not start — that is expected on some distros. The installer detects it, installs the runtime libraries, and falls back to a source build automatically.

The source build fails — install the dev packages for your distro and run the command again. On Debian/Ubuntu: sudo apt install build-essential pkg-config libssl-dev libgtk-3-dev libwebkit2gtk-4.1-dev libsoup-3.0-dev.

Updating — run the same command again. It stops the running copy, replaces the binary, refreshes yt-dlp, and relaunches.

Uninstalling — rm -f ~/.local/bin/rustify ~/.local/bin/yt-dlp ~/.local/share/applications/rustify.desktop; rm -rf ~/.local/share/rustify.
